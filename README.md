# Circuitos Eletropneumáticos e Eletro-hidráulicos Aplicados à Manufatura

Material da unidade curricular do curso Técnico em Mecatrônica do SENAI.
Instrutor: Iago Teixeira.

**Apresentação:** https://iagoot23.github.io/circuitos-eletropneumaticos-e-eletro-hidraulicos/

## Conteúdo

- `apresentacao/`: slides em HTML. A fonte fica em `src/`; para gerar o arquivo final, execute `python3 apresentacao/build.py`.
- `planejamento/`: cronograma de aulas, gerado por `python3 planejamento/gera_planilha.py "planejamento/Cronograma de Aulas.ods"`.
- `modelos/`: modelo de atividade.
- `info-unidade-curricular.txt`: dados da unidade curricular.

Navegação nos slides: setas do teclado, botões do rodapé ou tecla `M` para o mapa de dias.
